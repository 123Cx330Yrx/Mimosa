# Mimosa 双语版本交付说明

交付日期：2026-07-31

## 本轮完成内容

- 系统提供完整的中文与英文运行版本，不是仅用于截图的英文页面。
- 右上角可随时切换语言；`?lang=en` 可直接打开英文参与者或研究观察端。
- 房间 ID 默认留空；`room=` 仅用于按实验组预填，不同编号支持多组实验并行。
- JaaS App ID 仍由部署配置提供，不等同于房间 ID，也不要求参与者填写。
- 正式轮次中，幼苗长成含羞草后，叶片立即开始缓慢、连续地合拢，不再等待第二个 12 秒无回应阈值。
- 含羞草保留轻微、有机的生命感摆动，并支持减少动态效果的系统设置。
- 植物场景改为透明覆盖层，并与 Jitsi 底部工具栏保持安全间距。
- 植物说明改为中英文“小助手”对话气泡，随当前植物状态与环境变化更新。
- 中英文环境组合文案、观察端、角色确认、匿名回应、关怀动作、种子暂存和日志入口均已纳入同一语言系统。

## 推荐入口

```text
中文参与者：https://mimosa-srtp.com/?study=1&room=G01-task1
英文参与者：https://mimosa-srtp.com/?study=1&room=G01-task1&lang=en
中文观察端：https://mimosa-srtp.com/?research=1&room=G01-task1
英文观察端：https://mimosa-srtp.com/?research=1&room=G01-task1&lang=en
```

实际使用时请把示例房间 ID 换成该实验组的唯一编号。
